# Лабораторная работа №2. Подготовка скриптов и ETL-процесс для SQLite

## Описание проекта
Проект реализует процесс ETL для переноса данных в реляционную базу данных SQLite. Утилита на языке Go генерирует SQL-скрипт db_init.sql, который очищает старые таблицы, создает новую структуру и заполняет их информацией.

## Требования к окружению
Для запуска скриптов на компьютере должны быть установлены:
- Язык программирования Go
- Консольная утилита SQLite3

## Инструкция по запуску
1. Убедитесь, что исходные текстовые файлы с данными находятся в папке Task02.
2. Запустите скрипт db_init.bat в терминале.
3. В результате выполнения будет создана база данных movies_rating.db.
